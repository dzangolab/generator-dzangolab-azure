# generator-dzangolab-azure

A Yeoman generator (collection of generators) that scaffolds Pulumi TypeScript projects, and an Ansible folder, to provision Azure resources and Docker Swarm clusters.

This repository currently holds technical documentation only. No generator code is written until the specs and the design, testing, and implementation docs are reviewed.

- [Specs](specs/index.md) — one technical spec per feature, in `specs/`.
- [Design](docs/design.md) — chosen architecture, with C4 diagrams.
- [Testing plan](docs/testing-plan.md) — golden-tree diff, composition, and unit tests.
- [Implementation plan](docs/implementation-plan.md) — generator order and milestone cadence.
